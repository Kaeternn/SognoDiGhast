# SognoDiGhast - by Kaeternn
A simple yet configurable plugin to boost happy ghast speed.
## Installation
This plugin require [Paper](https://papermc.io/downloads/paper).

It's simple and fast to install this plugin, all you have to do is putting this plugin in your ``/plugins`` folder.
## Configuration
- ``debug``, add debug messages in console, I don't recommand enabling it if not necessary.
- ``speed-multiplier``, happy ghast's flying speed will be multiplied by this value.
- ``min-height``, minimum height to the multiplier taking effect. (note that player's coordinate is ~3 blocs above happy ghast's)
## Usage
Just let your players fly away with their faster ghasts.

There is two admin commands too :
- ``/sdg version`` tell you which version is installed on your server.
- ``/sdg reload`` reload the configuration if your want to update values without reloading the server.
